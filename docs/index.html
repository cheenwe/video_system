功能一览

前台面向观众与 UP 主，后台面向管理员与内容维护者，参考 B 站 / YouTube 的浏览与播放体验。

▶

前台播放体验

B 站风格 UI，HTML5 流式播放、断点续传、相关推荐与专辑分集；点赞、收藏、分享，评论游客可预览。

⇄

智能转码

上传 MOV / MKV / AVI / WebM 自动转为可播的 MP4 (H.264 + AAC)；已是 H.264 的文件优先 重封装，秒级完成。

⚡

弱网流畅播放

HLS 多码率自动降档 + MP4 Range 回退，关键帧对齐、真实码率探测，「流畅优先」一键锁档。

✎

投稿与上传

分片上传大文件（默认上限 5GB）、封面裁剪、分类与专辑关联；隐私视频专区登录可见。

▦

管理后台

数据概览、视频 / 专辑 / 分类 / 用户 / 评论管理，站点外观自定义（Logo、主题色、版权），操作日志与服务器指标。

◈

安全与权限

JWT 会话、加密播放链接（不暴露数字 ID）、限时免登录分享、游客播放开关、可选定时数据库备份邮件。

弱网播放链路

默认 HLS 多码率（主档 + 480p + 360p，可开 240p），弱网自动降档、有限重试，全程可观测。

快速开始

两种方式，均默认监听 8808 端口；默认管理员 admin，生产环境务必修改密码与 SECRET_KEY。

本地运行 · venv
# 1. 安装依赖（转码需本机 ffmpeg）
python -m venv .venv && source .venv/bin/activate
pip install -r requirements.txt
cp .env.example .env

# 2. 建表 + 默认管理员
python scripts/init_data.py

# 3. 启动
python -m uvicorn src.main:app --host 0.0.0.0 --port 8808
Docker Compose · 含 MySQL/Redis/Nginx
# SQLite 单机（含 Redis）
docker compose --profile sqlite up -d --build

# MySQL 生产（Nginx 反代）
docker compose --profile prod --profile mysql up -d --build

# 健康检查
curl -fsS http://127.0.0.1:8808/api/health
